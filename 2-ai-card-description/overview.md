# AI Card Description Generator (LLM-Assisted Content Creation)

## 1. Project Overview

This feature enables users to instantly generate a clear, polished card description using AI.  
Instead of manually writing long explanations, users can:

1. Enter a short prompt (e.g., “this task is about updating profile settings”)  
2. Click the AI Assistant button  
3. Receive a full, well-structured description generated by an LLM  
4. Edit or refine the result if needed  

The system uses the card title + the user’s brief input + metadata to produce contextual, high-quality descriptions that improve clarity and consistency across the platform.

---

## 2. High-Level Architecture

1. User clicks **“Generate description with AI”** on a card.  
2. A modal or input field asks: **“What is this card about?”**  
3. User provides a short explanation (1–2 sentences).  
4. Backend takes:
   - user input  
   - card title  
   - card context  
   - metadata (optional)  
5. A prompt is built and sent to **OpenAI Chat Completions**.  
6. The LLM returns a complete, multi-sentence description.  
7. The frontend populates the card description field automatically.  

**Summary:**  
`User Input → Prompt Builder → OpenAI → Generated Description → Auto-fill UI`

---

## 3. Example Prompt + Response Flow

### **Prompt sent to OpenAI (simplified):**

```txt
You are an assistant that helps users write clear, well-structured card descriptions.

Card Title: "Update Employee Profile Flow"
User Explanation: "We want to redesign the profile section and improve the update process"

Write a detailed but concise card description that:
- explains the purpose
- gives context
- outlines what should be improved
- uses a friendly and clear tone
```

### Example LLM Response:
This task involves improving the Employee Profile update flow.  
The current process requires multiple clicks and is not intuitive for new users.

The goal is to redesign the profile section to make common actions—such as updating personal info, uploading photos, or editing contact details—more straightforward.

The updated flow should prioritize clarity, reduce the number of steps required, and ensure consistency with the rest of the app's design system.

## 4.Pseudocode
```
def generate_card_description(card_title, user_prompt):
    system_prompt = (
        "You are an assistant that writes clean and helpful task descriptions."
    )

    final_prompt = f"""
    Card Title: {card_title}
    User Explanation: {user_prompt}

    Write a clear, detailed, and concise card description.
    """

    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": final_prompt},
        ]
    )

    return response.choices[0].message["content"]
```
## 5.How I Used AI During Development
I used ChatGPT to:

- Test variations of the system prompt

- Improve clarity and reduce verbosity in descriptions

- Experiment with different tones (professional, concise, friendly)

- Validate edge cases (very short user prompts, vague prompts, overly long prompts)

- Suggest alternative description structures

This made the feature faster to build and improved the quality of the final outputs.
