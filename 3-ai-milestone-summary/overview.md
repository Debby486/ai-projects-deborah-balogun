# AI Milestone Summary Generator (Data Insights + AI Retrospective Assistant)

## 1. Project Overview

This feature automatically generates a complete milestone summary at the end of each sprint by combining:

- **Data analytics** (hours, contributors, categories)
- **Interactive charts** (bar + pie)
- **AI-generated narrative analysis**

The system analyzes milestone activity, visualizes key metrics, and then uses OpenAI to produce a clear, structured retrospective summary. This eliminates the time-consuming manual reports usually written by team leads.

---

## 2. What the Summary Includes

The milestone summary contains:

### ✅ **1. Top 5 Contributors**  
Ranked by the number of hours spent on subtasks categorized as **“Development”**.

### ✅ **2. Estimated vs Actual Hours (Bar Chart)**  
Shows estimation accuracy and dev effort across the sprint.

### ✅ **3. Subtasks Category Breakdown (Pie Chart)**  
Displays how many hours were spent on:

- Development  
- Code Review  
- QA Review  
- Sync  
- Others  
 

This blend of **data + AI interpretation** gives teams both objective reporting and contextual understanding.

---

## 3. High-Level Architecture

1. Each milestone → contains cards → each card contains subtasks.  
2. For every subtask, the system collects:
   - task name  
   - category (generated by AI)  
   - time spent  
   - estimated hours  
   - status (done, in progress, blocked)  
   - contributor  

3. Backend aggregates data:
   - total actual hours  
   - total estimated hours  
   - hours per category  
   - contributor ranking  

4. AI categorizes each subtask into one category (strictly one).  
5. Colors for the categories are generated using a Matplotlib color map.  
6. Bar and pie charts are rendered on the frontend.  
7. A JSON payload summarizing the milestone is sent to **OpenAI**.  
8. LLM returns a final natural-language milestone summary.  

**Summary:**  
`Milestone Data → AI Categorization + Aggregation → Charts → LLM Summary → Final Report`

---

## 4. AI-Driven Subtask Categorization

AI is used to strictly assign each subtask to **exactly one category**.  
The LLM receives instructions to:

- keep task names **exactly** as-is  
- preserve prefixes like `[Leads Task]`  
- not wrap output in backticks or markdown  
- return a JSON list with:  
  ```json
  [{"category": "...", "task": "..."}]
  ```
## Example categorization prompt:
STRICTLY CATEGORIZE EACH TASK INTO ONE CATEGORY ONLY.
Assign each task a category such as Development, Code Review, QA Review, Sync, or Others.

Return the result as a list of JSON objects:
[
  {"category": "Development", "task": "Fix avatar upload"},
  {"category": "QA Review", "task": "[Leads Task] Review task validation rules"}
]

Important:
- DO NOT change any task names.
- DO NOT remove any prefixes like “[Leads Task]”.
- DO NOT wrap output in backticks.
- Return JSON only.

## 7.Pseudocode
```
def generate_milestone_summary(milestone_id):
    subtasks = extract_subtasks(milestone_id)

    # Contributor ranking
    contributors = rank_contributors(subtasks, category="Development")

    # Hours
    estimated = sum(s.estimated_hours for s in subtasks)
    actual = sum(s.actual_hours for s in subtasks)

    # AI categorization + color assignment
    categorized = ai_categorize_tasks(subtasks)
    category_data = compute_category_hours(categorized)

    # Build final payload
    payload = {
        "milestone_name": milestone.name,
        "contributors_ranked": contributors,
        "total_estimated_hours": estimated,
        "total_actual_hours": actual,
        "categories": category_data,
        "subtasks": split_subtasks(subtasks)
    }

    # Generate narrative summary with LLM
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": "You summarize sprint work clearly."},
            {"role": "user", "content": json.dumps(payload)}
        ]
    )

    return response.choices[0].message["content"]
```
## 8.Design Decisions
- Combine analytics + AI for richer, actionable sprint insights
- Use AI for category classification to avoid hard-coded mappings
- Use color maps for consistent chart styling
- Use strict JSON prompts to reduce hallucinations
- Use ranked contributors for transparency and motivation
- Provide both charts and narrative for a full understanding
